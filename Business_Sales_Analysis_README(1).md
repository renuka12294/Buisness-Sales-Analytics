
# 📊 Business Sales Analysis Dashboard

## 📌 Project Overview

Sales data contains valuable business insights, but extracting meaningful information from raw data is difficult. This project cleans, transforms, analyzes, and visualizes business sales data to uncover trends, evaluate regional performance, and support data-driven decision-making through an interactive Power BI dashboard.

---

## 🛠️ Tech Stack

- Python
- Jupyter Notebook
- Pandas
- MySQL
- SQL
- Microsoft Excel
- Power BI

---

## 🔄 Project Workflow

1. Import data from Excel.
2. Clean and preprocess using Python (Pandas).
3. Store the cleaned dataset in MySQL.
4. Perform Exploratory Data Analysis (EDA).
5. Build an interactive Power BI dashboard.

---

## 📊 Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Profit Margin KPI
- Monthly Sales Trend
- Profit by Region
- Product-wise Sales Analysis
- Year and Region Filters

---

## 📈 Business Questions Answered

- What are the total sales and profit?
- Which month recorded the highest sales?
- Which region generates the highest profit?
- Which products contribute the most revenue?
- How does sales performance vary over time?
- Which regions require improvement?
- What is the overall profit margin?
