## 📌 Project Overview

The **Business Sales Analysis Dashboard** is an end-to-end data analytics project designed to transform raw business sales data into meaningful insights that supportstrategic 
decision-making. The project demonstrates the complete data analysis pipeline, starting from data collection and preprocessing to database management, exploratory data analysis
(EDA), and interactive dashboard development.

The raw sales dataset was imported from **Microsoft Excel**, cleaned and preprocessed using **Python (Pandas & NumPy)** in **Jupyter Notebook**, and stored in **MySQL** for 
efficient querying and data management. Exploratory Data Analysis (EDA) was then performed to identify sales trends, product performance, regional profitability, and overall 
business performance.

Finally, an interactive dashboard was developed using **Power BI** to visualize key business metrics such as Total Sales, Total Profit, Profit Margin, Monthly Sales Trends, 
Product-wise Sales, and Regional Profit Distribution. Interactive filters and slicers allow users to explore the data dynamically and gain actionable insights.

This project demonstrates practical skills in **data cleaning, SQL querying, data visualization, business intelligence, and dashboard development**, making it suitable for
real-world business analytics and reporting scenarios.
